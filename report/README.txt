Ce dossier contient les rapports generes par le pipeline.

A chaque scan (lancement de main.py ou start.py), un sous-dossier est cree
automatiquement avec la date et l'heure du scan, par exemple :

report/2026-11-03_12-30-47/report_global.txt
report/2026-11-03_12-30-47/report_local.txt

Ces sous-dossiers ne sont pas versionnes dans git (voir .gitignore).
